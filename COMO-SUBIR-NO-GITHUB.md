# Como publicar a entrega 1

1. O grupo já clonou o material de https://github.com/Felippe-Pires/template_projects. Esta pasta contém o preenchimento da Entrega 1 na estrutura original.
2. Crie um repositório na conta do grupo. Na página consultada, o botão **Use this template** não estava disponível; registre a origem no README e confirme com o professor a aceitação dessa forma de derivação. Não há comprovação automática de "generated from template" por apenas clonar.
3. Nome sugerido: **agenda-ao-ar-livre**. Escolha a visibilidade conforme a orientação da disciplina; se privado, conceda acesso ao professor.
4. No novo repositório, use **Add file > Upload files**.
5. Envie o **conteúdo** desta pasta: README.md e as pastas docs, images e scripts, além dos demais arquivos. O README deve ficar na raiz do repositório, e não dentro de outra pasta agenda-ao-ar-livre.
6. Inclua também **.gitignore** e **.env.example**; eles podem estar ocultos no seu computador. .env.example contém somente exemplos, sem segredos. Não envie um .env real.
7. Preserve os caminhos dos arquivos. Se preferir GitHub Desktop, clone o novo repositório e copie o conteúdo desta pasta para ele, sem copiar .git. O origin do clone atual aponta para o professor; não envie alterações para esse destino.
8. Escreva uma mensagem, por exemplo **docs: adiciona proposta inicial da entrega 1**, revise as alterações e confirme o envio.
9. Adicione a conta do outro integrante nas configurações de colaboradores. Cada pessoa precisa aceitar o convite e fazer contribuições reais de revisão/correção com sua própria conta.
10. Complete os dados acadêmicos pendentes no README e em docs/planejamento/submissao.md. Atualize a documentação PDF se alterar seu conteúdo.
11. Verifique se o professor consegue abrir o repositório, os PDFs, os SVGs e os arquivos editáveis.
12. Após a revisão final, registre a URL e o commit/tag da entrega em docs/planejamento/submissao.md. A tag sugerida é **entrega-1**, criada somente quando o grupo considerar a versão final.

## O que enviar
Os arquivos descompactados, mantendo as pastas. Não envie apenas o ZIP: o professor precisa navegar pela documentação no GitHub.

## Como visualizar
- README.md: ponto de entrada.
- docs/entrega-1.pdf: documentação consolidada.
- docs/prototipos/index.html: abrir no navegador local para navegar nas telas.
- docs/prototipos/*.png: capturas para consulta no GitHub.
- Arquivos .drawio: abrir no diagrams.net para editar diagramas.

A aplicação Django ainda não está implementada; esta pasta corresponde à fase 1. A geração inicial com auxílio de IA está declarada no README. O pacote não substitui revisão, entendimento e contribuições individuais da dupla.
